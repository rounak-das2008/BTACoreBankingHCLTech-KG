● Context Contamination
  Irrelevant tokens corrupt reasoning quality
● Low Signal-to-Noise Ratio
  Useful signal drowns in boilerplate noise
● Lost in the Middle
  Facts buried deep in context get silently ignored
● Attention Dilution
  Too many tokens competing, focus scatters

    Principles of Context Engineering


● Progressive Disclosure —
  Reveal information to agents strictly as their role requires. Structure
  before content. Boundaries before reads.
● Deterministic Grounding —
  Use fast, deterministic tooling for structural work. Reserve LLM context
  exclusively for semantic reasoning.
● Role Isolation —
  One agent, one competency, one narrow context. Specialisation
  eliminates hallucination and instruction drifts.
● Subagent Isolation —
  Delegate cognitive tasks to disposable subagent contexts. Keep the
  orchestration layer uncontaminated.

    Lessons from Production


● Validate early —
  Trust in generated documentation must be earned, not assumed.
● Evolve the tools —
  The pipeline is not dogma. If a tool underperforms, replace it. The
  architecture holds.
● Evolve freely —
  Decoupled layers evolve independently. The contract between layers is
  the only thing that must be honoured.
● Respect the economics —
  Match the instrument to the problem. The full pipeline justiﬁes its cost only
  when a holistic view is needed.
